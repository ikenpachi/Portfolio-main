# Corrosivo | Igor Ribeiro

Meu portfólio pessoal, onde compartilho projetos, minha trajetória profissional e o interesse por Cybersecurity, Offensive Security e Red Team.

[Acesse o portfólio](https://ikenpachi.github.io/Portfolio-main/)

O site reúne experiências, formação e ferramentas com as quais trabalho e estudo. A identidade visual combina ciano e verde, tipografia técnica e um globo pontilhado interativo com uma lua menor. Tem temas claro e escuro e layout adaptado para celular e desktop.

Desenvolvido com **HTML, CSS e JavaScript**, usando Canvas 2D para a animação e GitHub Pages para hospedagem.

## Executar localmente

Abra o `index.html` no navegador ou use o Live Server do VS Code.

Para gerar o JavaScript após editar os módulos, utilize Node.js 18 ou superior:

```sh
node scripts/build.mjs
```
